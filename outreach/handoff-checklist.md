# Same-day handoff

- [ ] Confirm in writing: $200 one time for site, setup, free GitHub Pages hosting, and one year of small edits (hours, prices, photos, text). New features quoted separately. Payment due only if they keep it, at final approval and go-live; no required monthly fee.
- [ ] Owner approves final hours, phone, prices, photos/reuse rights, spelling, address/map, and all other content. Save approval privately.
- [ ] Preview changes: `node go-live.js <slug> [edits.json] --dry-run`. Then run `node go-live.js <slug> [edits.json]` (omit brackets and optional filename if unused). Review generated output, commit, and deploy via GitHub Pages. This builds locally, not a remote deployment. Check the final URL, phone link, photos, and that the Preview ribbon and noindex are gone.
- [ ] Payment received/cleared: record method, amount, date, and transaction/check reference privately. Cash App $absubedi, PayPal to <PayPal email>, cash, or check (deposited in Cash App). Confirm the PayPal email before sending payment details. Do not store receipts or customer payment records in this public repo.
- [ ] Optional domain: shop buys/owns the domain in its own name/account, at cost (~$12/year; check renewal price). A domain belongs to a Pages repository, not a slug: use a separate customer repo and adapt output/canonical URLs for its publishing root before connecting it.
- [ ] In that repo's Settings > Pages, set the custom domain. At the registrar, follow [GitHub's current DNS instructions](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site): subdomain CNAME points to `<account>.github.io` (no path); apex uses GitHub's documented A/AAAA records or supported ALIAS/ANAME. Complete domain verification, wait for DNS, then enable HTTPS and test both intended hostnames. Never point DNS at a `/slug/` URL.
- [ ] Preserve/reapply the publishing-root `CNAME` on every build: this generator deletes all of `docs/`, including hand-added `CNAME`. See [README custom-domain notes](../README.md#after-payment--handoff). Supply source/export, account access, and renewal details to the owner.
- [ ] Ask owner to add the final link in their Google Business Profile: **Edit profile > Website**, then save. Do not do this for them without authorized profile access; never request their password.
- [ ] Send final link + receipt using [reply scripts](replies.md#final-link--receipt); include the launch date, year-one end date, and how to request edits.
- [ ] Set a private reminder before the included year ends. Offer optional $15/month updates after year one, opt-in only, no automatic enrollment or double billing.
